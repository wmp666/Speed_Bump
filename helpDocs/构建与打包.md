# 构建与打包

## 环境要求

- **JDK 21+**：项目使用了虚拟线程（`Thread.ofVirtual()`）、`record`、switch 模式匹配、`List#getFirst`、`Math#clamp` 等特性
- IntelliJ IDEA（工程文件为仓库根目录的 `DownLoader.iml`）
- 入口类：`com.wmp.downloader.Run`

## 依赖

依赖 jar 统一放在仓库的 `lib/` 目录，由 IDEA 模块的 library 引用：

- FlatLaf、FlatLaf Extras、FlatLaf SwingX
- SwingX（`swinglabs.swingx.all`）
- fastjson / fastjson2
- jsoup、log4j、commonmark、commons-net
- zxing core + javase（扫码登录相关）
- modal-dialog（`io.github.dj.raven`）
- jlibtorrent 2.0.12.9：核心 jar + 平台原生库

其中 jlibtorrent 原生库当前包含：

| 平台 | 是否提供 |
| --- | --- |
| Windows | ✅ `jlibtorrent-windows-2.0.12.9.jar` |
| Linux `x86_64` | ✅ `jlibtorrent-linux-x86_64-2.0.12.9.jar` |
| Linux `arm64` | ✅ `jlibtorrent-linux-arm64-2.0.12.9.jar` |
| macOS | ❌ 需自行补充对应原生库，否则 BT 功能不可用 |

`lib/` 中还放有 `java-youtube-downloader`，目前未接入主流程。

图标资源位于 `src/icon/` 与 `src/com/wmp/speed_bump/common/background/resource/icon/`（后者为迁移中的新资源路径）。

## 构建

用 IDEA 直接构建 / 导出 jar 即可，产物默认输出到 `out/`：

- Windows：导出 `DownLoader_Windows_jar`
- Linux：导出 `DownLoader_Linux.jar`

## 打包

### Windows

1. 由 exe4j 依据 `out/SpeedBump.exe4j` 生成 `SpeedBump.exe`
2. 由 Inno Setup 依据 `out/减速带.iss` 生成安装包（脚本中引用了 `out/artifacts/DownLoader_Windows_jar/*` 与 exe4j 的输出目录）

### Linux

```bash
jpackage --input /path/to/SpeedBump --main-jar DownLoader_Linux.jar \
         --main-class com.wmp.downloader.Run --icon /path/to/icon.png \
         --name SpeedBump --type deb --dest /path/to/JarDebs

dpkg-deb --build --root-owner-group /path/to/package /path/to/JarDebs/Speed_Bump_Setup_<版本>.deb
```

## 运行期目录

程序运行时会使用用户目录下的 `~/.speed-bump`（配置、拓展、日志、默认下载目录），详见 [使用指南 · 数据与日志](使用指南.md#五数据与日志)。
