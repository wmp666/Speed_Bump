# 下载用

| key               | value                          |
|-------------------|--------------------------------|
| rootName          | 名称                           |
| partNames         | 各个文件名                     |
| savePath          | 保存路径                       |
| mode              | 链接模式                       |
| threadMode        | 下载模式（单/多）              |
| threadNum         | 下载线程数                     |
| url               | 下载链接                       |
| size              | 文件大小                       |
| sizes             | 各个文件大小数据               |
| selectedUrls      | 选择的文件的链接               |
| selectedFileNames | 选择的文件的名称               |
| selectedStatus    | 各个文件的选择状态             |
| linkStyle         | 链接类型（0-单文件；1-多文件） |
