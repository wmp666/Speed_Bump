# 减速带 (Speed Bump)
1. 多线程 + 单线程下载工具，支持HTTP，HTTPS，BT（Torrent、Magnet），ED2K
2. 视频处理器，支持合并音频，视频；

## 使用提示（单文件运行）
1. 运行本软件时请确保已安装(有相关的环境变量——JAVA_HOME/JDK_HOME) **Java 25** 或更高版本，或者在程序同目录下放置JDK文件夹，并重命名为jdk

## 支持的下载链接
- HTTP/HTTPS
  - Github加速
- BT（Torrent、Magnet）
- Gopeed

### 官方提供的拓展支持格式
- 哔哩哔哩（视频、视频合集）
- 抖音（视频、图集）

## 支持的视频处理
- 视频合并
- 视频转码，转格式

## 功能

### 可用操作
- 将文件拖入创建任务的文本框中，快速添加文件
- 设置背景图，并修改亮度（Alpha）
- 在拓展页下载拓展，丰富功能
- 在关闭任务时，选择是否删除本地文件
- 可以将已完成的任务以文件的形式实现拖拽操作
